# ShoeShop 文档

## 项目概述

ShoeShop 是一个基于 Shopify Headless 架构的运动鞋独立电商网站，面向欧美市场，通过 SEO + GEO（全球英文优化）策略获取自然流量。

**目标用户**: 欧美地区的运动鞋消费者，年龄 18-45 岁，对运动鞋品质和品牌故事有要求的用户群体。

**核心价值**:
- 高质量运动鞋产品与专业的尺码选购指南
- 多语言多币种本地化购物体验
- 深度的运动鞋评测/穿搭内容驱动用户决策
- 极致的 SEO 优化确保搜索引擎可见性

## 技术选型

| 类别 | 选择 | 理由 |
|------|------|------|
| 前端框架 | SvelteKit | SSR/SSG 天生支持，对 SEO 友好，打包体积小 |
| UI 方案 | Tailwind CSS | 原子化 CSS，快速开发，与 SvelteKit 集成良好 |
| 电商后端 | Shopify Storefront API | 成熟电商平台，商品/订单/库存管理开箱即用 |
| 支付 | PayPal | 欧美市场主流支付方式 |
| 内容管理 | Shopify CMS + 本地 Markdown | 产品数据走 Shopify，博客内容本地管理 |
| 部署 | Cloudflare Pages | 全球 CDN，边缘函数，免费额度充足 |
| 构建工具 | Vite (SvelteKit 内置) | 快速 HMR，生产构建优化 |

## 核心功能

### 商品管理
- **目的**: 展示和管理运动鞋产品信息
- **描述**: 通过 Shopify Storefront API 获取商品数据，在前端实现产品列表、搜索筛选、详情展示、多属性 SKU 选择等功能

### 国际化
- **目的**: 覆盖欧美多语言市场
- **描述**: 初期支持英语、法语、德语、意大利语、西班牙语，基于 SvelteKit 的 i18n 方案实现多语言路由、多币种切换、本地化内容管理

### 用户系统
- **目的**: 用户注册登录，订单管理
- **描述**: 通过 Shopify Customer API 实现用户认证、地址管理、订单历史和收藏功能

### 内容营销
- **目的**: SEO 流量获取和用户教育
- **描述**: 内置博客系统，支持运动鞋评测、穿搭指南、尺码指南、品牌故事等深度内容，配合结构化数据标记提升搜索排名

### 购物车与结账
- **目的**: 流畅的购买体验
- **描述**: 本地购物车状态管理，通过 Shopify Checkout API 完成支付流程
